# Blog Spirituel — Janice Yamthieu

Site vitrine/blog développé en freelance pour une cliente, dédié à la publication de contenus sur le thème spirituel. Interface Angular responsive permettant à la cliente de partager ses articles avec sa communauté.

## 🎯 Contexte

Projet réalisé pour une cliente indépendante souhaitant disposer d'un espace de publication personnel, simple à parcourir et accessible sur mobile comme sur desktop.

## ✨ Fonctionnalités

- **Articles / publications** — affichage des contenus publiés par la cliente
- **Catégories et navigation** — organisation des articles par thématique
- **Recherche de contenu** — recherche d'articles au sein du blog
- **Formulaire de contact** — permet aux visiteurs de contacter la cliente directement depuis le site
- **Design responsive** — expérience adaptée mobile et desktop

## 🛠️ Stack technique

| Composant | Technologie |
|---|---|
| Framework | Angular |
| Type | Frontend uniquement |

## 🚧 État du projet

Application frontend fonctionnelle, livrée dans le cadre d'une mission freelance.

## 🚀 Installation

```bash
# Cloner le repo
git clone https://github.com/nkkodia/blog-janice-yamthieu-angular.git
cd blog-janice-yamthieu-angular/blog-spirituel

# Installer les dépendances
npm install

# Lancer le serveur de développement
ng serve
```

L'application est ensuite accessible sur `http://localhost:4200`.
